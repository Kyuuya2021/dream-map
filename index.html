Dream Map Project 規約

本プロジェクトにご参加いただくにあたり、以下の規約にご同意ください。

  1. 投稿内容について：公序良俗に反する内容、他者を誹謗中傷する内容、法令に違反する内容の投稿を禁止します。
  2. 個人情報の取り扱い：登録されたニックネーム・夢・写真・位置情報は地図上に公開されます。紹介者情報は運営のみが確認し、公開しません。
  3. 知的財産権：投稿された内容の著作権は投稿者に帰属しますが、本プロジェクトの広報・紹介目的での使用を許諾いただきます。
  4. 運営の権利：運営は事前の通知なく、不適切と判断した投稿を削除する権利を有します。
  5. 免責事項：本サービスの利用により生じた損害について、運営は一切の責任を負いません。
  6. 規約の変更：運営は必要に応じて本規約を変更できるものとし、変更後の規約は本ページに掲示した時点で効力を生じるものとします。
